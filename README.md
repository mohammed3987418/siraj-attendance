# نظام حضور الطلبة ببصمة الوجه (PWA)
جامعة السراج — قسم هندسة تقنيات الذكاء الاصطناعي (صباحي / مسائي)

## محتويات المجلد
| الملف | الوظيفة |
|---|---|
| `index.html` | واجهة التطبيق |
| `app.js` | منطق التطبيق: التعرف على الوجه، الحضور، المزامنة، الصلاحيات |
| `sw.js` | يجعل التطبيق يعمل دون إنترنت بعد أول فتح |
| `manifest.webmanifest` + `icons/` | تثبيت التطبيق على الحاسوب أو التابلت بأيقونة |
| `firebase-config.js` | **الملف الوحيد الذي تعدّله**: إعدادات مشروع Firebase |
| `firestore.rules` | قواعد الحماية، تُلصق في Firebase Console |

> إذا تركت `firebase-config.js` فارغاً يعمل التطبيق بوضع **محلي تجريبي**، أي تُحفظ البيانات على الجهاز فقط. هذا مفيد للتجربة قبل الربط.

---

## أولاً: تجهيز Firebase (مرة واحدة)
في مشروع **siraj-ai-students** على https://console.firebase.google.com

1. **Authentication** ← Get started ← Sign-in method ← فعّل **Email/Password**.
2. **Firestore Database** ← Create database ← اختر Production mode وأقرب منطقة (مثل `europe-west`).
3. **Firestore ← Rules**: الصق محتوى `firestore.rules` ثم اضغط Publish.
   - إذا كانت لديك قواعد سابقة لنظام شؤون الطلبة، **أضف** كتل `match /att_...` إليها ولا تحذف القديم.
4. **Project settings (⚙) ← Your apps ← Web (</>)**: سجّل تطبيق ويب، ثم انسخ قيم `firebaseConfig` إلى ملف `firebase-config.js`.
5. **Authentication ← Settings ← Authorized domains**: أضف نطاق GitHub Pages الخاص بك، مثل `username.github.io`.

### إنشاء حساب رئيس القسم الأول (يدوياً مرة واحدة)
1. **Authentication ← Users ← Add user**: أدخل بريدك وكلمة مرور، ثم انسخ **User UID**.
2. **Firestore ← Start collection**: اسم المجموعة `att_users`، ومعرّف المستند (Document ID) = **الـ UID الذي نسخته**، والحقول:
   - `name` (string): اسمك
   - `email` (string): بريدك
   - `role` (string): `admin`

بعد ذلك تُنشأ بقية الحسابات (التدريسيون وموظفو التسجيل) من داخل التطبيق، من تبويب **المستخدمون**.

## ثانياً: النشر على GitHub Pages
1. أنشئ مستودعاً جديداً، مثل `siraj-attendance`.
2. ارفع **كل الملفات مع مجلد `icons`** إلى جذر المستودع.
3. **Settings ← Pages ← Branch: main / (root) ← Save**.
4. بعد دقيقة يصبح الرابط: `https://username.github.io/siraj-attendance/`

## ثالثاً: التثبيت على أجهزة القاعات
1. افتح الرابط في **Chrome أو Edge** مع اتصال بالإنترنت، ثم سجّل الدخول.
2. انتظر حتى تظهر **"نماذج الوجه جاهزة ✓"** في أعلى الشاشة. عندها تُحفظ النماذج على الجهاز (نحو ١٠ ميغابايت، مرة واحدة فقط).
3. اضغط **⬇ تثبيت التطبيق** في أعلى الشاشة، أو من قائمة المتصفح اختر "تثبيت التطبيق". تظهر بعدها أيقونة على سطح المكتب.
4. اسمح للتطبيق باستخدام الكاميرا عند أول طلب.

من هنا يعمل التطبيق **دون إنترنت**: يُحفظ الحضور على الجهاز ويُرفع تلقائياً عند عودة الاتصال، حتى لو أُغلق التطبيق وفُتح لاحقاً. ويوضح المؤشر في أعلى الشاشة حالة الرفع.

## الصلاحيات
| الدور | يستطيع |
|---|---|
| رئيس القسم (`admin`) | كل شيء، وإدارة المستخدمين، وكل السجلات، وحذف المحاضرات، والنسخ الاحتياطي |
| موظف تسجيل (`registrar`) | إضافة الطلبة وتسجيل بصماتهم |
| تدريسي (`instructor`) | أخذ الحضور، ورؤية سجلات محاضراته فقط |
| معطّل (`disabled`) | لا يستطيع الدخول |

## مجموعات قاعدة البيانات
- `att_users/{uid}`: الاسم والبريد والدور
- `att_students/{رقم جامعي}`: الاسم والمرحلة والدراسة والشعبة
- `att_faceprints/{رقم جامعي}`: البصمات الرقمية (٣ إلى ٥ متجهات × ١٢٨ رقماً). **لا تُحفظ الصور.**
- `att_sessions/{auto}`: محاضرة واحدة = مستند واحد يحوي قائمة الغائبين والحاضرين

## تحديث التطبيق لاحقاً
عند تعديل أي ملف، غيّر رقم `VERSION` في أعلى `sw.js` (مثلاً `att-app-v2.0.1`) ثم ارفع الملفات. تتحدث الأجهزة تلقائياً عند فتح التطبيق مع إنترنت.

## ملاحظات

- يمكن استيراد النسخة الاحتياطية من النموذج الأول (`attendance.html`) من تبويب الإعدادات ← استعادة / استيراد.
